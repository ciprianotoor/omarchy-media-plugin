# Changelog

## Restauración de la interfaz original

Se restauró la apariencia original del plugin anterior a las pruebas de
personalización visual y al botón textual para activar o desactivar Cava.

La decisión se tomó porque esos cambios modificaban demasiado la estética
compacta del plugin y no se veían de forma consistente mientras coexistían
instalaciones antiguas y nuevas del plugin en Omarchy. La versión restaurada
mantiene la experiencia original: controles MPRIS, arte del álbum, selección
de fuentes, notificaciones, controles del panel y visualizador Cava integrado.

El cambio afecta únicamente a la interfaz del plugin; no elimina el proyecto,
su manifiesto, la documentación, el script de actualización ni la licencia.
